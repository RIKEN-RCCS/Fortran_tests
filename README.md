# Fortran Tests

Tests of Fortran language features, run with LLVM's testing tool **lit** and checked with **FileCheck**.

| Directory | Contents |
|---|---|
| [F2008-Tests/](F2008-Tests/README.md) | Tests of Fortran 2008 features |
| [F2018-Tests/](F2018-Tests/README.md) | Tests of Fortran 2018 features |

Each directory has its own `lit.cfg.py` and `run_tests.sh`. See the README in each directory for how to run the tests.
